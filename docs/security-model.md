# Security Model

ESP-Deck is an experimental embedded platform. It should not be assumed to
provide strong security guarantees.

## Principles

- Tools should be modular.
- Security-sensitive features should require deliberate user action.
- Destructive or disruptive behavior should not be the default.
- Documentation should clearly identify authorized-use requirements.
- Sensitive credentials and keys must never be committed to Git.

## Reporting

See `SECURITY.md` for reporting vulnerabilities in the project itself.
