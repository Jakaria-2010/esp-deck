# Security Policy

## Scope

This policy covers vulnerabilities in the ESP-Deck/NexorOS project itself,
including firmware, documentation that creates a security issue, and
repository infrastructure.

## Supported version

| Version | Supported |
|---|---|
| Main / current development | Yes |
| Older prototype releases | Best effort |

## Reporting

Please report security vulnerabilities privately rather than posting
unpatched details publicly.

Include:
- affected version or commit;
- description of the issue;
- reproduction steps;
- potential impact;
- suggested mitigation, if known.

Do not include passwords, private keys, or other sensitive personal data.

## Responsible use of tools

ESP-Deck may eventually include dual-use security and radio tools. Their
availability does not authorize testing systems that you do not own or have
permission to test.

The project maintainers do not endorse unauthorized access, credential theft,
disruption, or other unlawful use.
