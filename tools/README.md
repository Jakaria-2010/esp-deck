# ESP-Deck Tools

This directory contains optional tools intended to run on ESP-Deck/NexorOS.

Tools are separated from the core operating system so they can be developed
and tested independently.

## Planned tools

- `ir/` — infrared hardware experimentation and learning tools
- `wifi/` — Wi-Fi diagnostics and authorized security-research tools

## Responsible use

Only use radio, infrared, networking, and security functions on hardware or
networks that you own or are explicitly authorized to test.

Do not use ESP-Deck to bypass access controls, steal credentials, disrupt
networks, or interfere with devices without permission.

Tool implementations should include clear safety notes and should avoid
defaulting to disruptive behavior.
