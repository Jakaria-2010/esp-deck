# Nexora GPIO Pinout

## Display
- GPIO10: OLED CS
- GPIO9: OLED DC
- GPIO8: OLED Reset
- GPIO12: SPI Clock
- GPIO11: SPI MOSI

## Storage
- GPIO14: SD CS
- GPIO13: SD MISO
- GPIO11: SD MOSI
- GPIO12: SD CLK

## Buttons
- GPIO16: Back
- GPIO7: Right
- GPIO15: OK/Center
- GPIO6: Left
- GPIO4: Up
- GPIO5: Down
